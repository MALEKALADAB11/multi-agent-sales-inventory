# L'Agent Analyse (stocks)

L'Agent Analyse calcule la situation de référence d'une référence produit dans un magasin donné, indépendamment de tout signal contextuel externe. Il récupère les données de stock, de prévision de demande et de contraintes d'approvisionnement, calcule les indicateurs de gestion de stock habituels tels que le nombre de jours de couverture restants, la quantité économique de commande et le point de commande, puis classe le risque associé selon deux niveaux de lecture croisés. Un modèle de langage intervient à la fin, non pas pour narrer les chiffres mais pour jouer le rôle d'évaluateur capable de repérer des contradictions entre les différentes dimensions du rapport, par exemple un risque annoncé comme critique alors que les indicateurs bruts ne le suggèrent pas. Cet agent fonctionne aussi bien en mode base de données qu'en repli sur un fichier si la base est indisponible, ce qui lui permet de continuer à produire un résultat même en cas de dégradation partielle de l'infrastructure. Son rapport, incluant l'état du stock, la prévision de demande et l'évaluation du risque, constitue la base sur laquelle l'Agent Décision va ensuite raisonner.

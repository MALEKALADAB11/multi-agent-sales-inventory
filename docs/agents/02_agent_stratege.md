# L'Agent Stratège (vente)

L'Agent Stratège prend le relais de l'Analyste pour proposer une tactique commerciale adaptée au moment présent. Il commence par rassembler le contexte externe du magasin : météo, jours fériés, événements locaux et offres actives, puis interroge une base documentaire vectorielle pour retrouver des scripts de vente ayant déjà fonctionné dans des situations comparables. Il analyse ensuite ces éléments pour identifier la cause racine de l'écart de performance signalé par l'Analyste et les facteurs contextuels qui l'expliquent, avant de générer, à l'aide d'un modèle de langage nourri par les scripts retrouvés, une stratégie concrète sous forme d'actions et de produits à pousser. Le résultat est mis en forme pour être exploitable par le frontend, puis l'agent applique une étape d'auto-critique dans laquelle il réévalue lui-même la cohérence et la complétude de sa proposition avant de la considérer comme définitive. Cette boucle d'auto-critique, inspirée du principe de réflexion, permet de rattraper une partie des incohérences avant même qu'elles n'atteignent le Guardrail.
